最简单的用法

引入一个 autoload.js 就够了。 它会自己加载样式、引擎、模型数据，然后在页面右下角放一只看板娘。 

<script src="https://cdn.jsdelivr.net/gh/whyyy-404/live2d-waifu@main/assets/autoload.js"></script>
就这一行。放在 <body> 结束前即可。 你现在看到的右下角那只，就是这么加载出来的。

想改默认参数？

在引入 autoload.js 之前定义一个全局对象， 它会覆盖内部默认值： 

<script>
  window.live2d_autoload = {
    modelId: 3,              // 默认角色：1 Pio / 2 Tia / 3 22娘 / 4 33娘 / 5 雫 / 6 海王星 / 7 舰娘
    modelTexturesId: 0,      // 默认皮肤，0 表示该角色的原皮
    waifuMinWidth: '768px',  // 页面窄于此宽度时隐藏，'disable' 表示不隐藏
    waifuEdgeSide: 'right:0' // 停靠位置，'left:0' 或 'right:0'
  };
</script>
<script src="https://cdn.jsdelivr.net/gh/whyyy-404/live2d-waifu@main/assets/autoload.js"></script>

手动控制加载

需要自己决定什么时候加载、或者要改更多参数时，按下面的顺序手动引入。 顺序不能乱 —— 引擎要先于静态 API，静态 API 要先于控制逻辑。 

<!-- 1. 样式 -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/element-ui@2.15.14/lib/theme-chalk/icon.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/whyyy-404/live2d-waifu@main/assets/waifu.css">

<!-- 2. 看板娘容器（结构固定，顺序有讲究） -->
<div class="waifu">
  <div class="waifu-tips"></div>
  <canvas id="live2d" class="live2d" width="280" height="250"></canvas>
  <div class="waifu-tool">
    <span class="el-icon-house"></span>
    <span class="el-icon-chat-dot-round"></span>
    <span class="el-icon-user"></span>
    <span class="el-icon-magic-stick"></span>
    <span class="el-icon-camera"></span>
    <span class="el-icon-view"></span>
    <span class="el-icon-discover"></span>
    <span class="el-icon-switch-button"></span>
  </div>
</div>

<!-- 3. 依赖与引擎 -->
<script src="https://cdn.jsdelivr.net/npm/jquery@3.3.1/dist/jquery.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/whyyy-404/live2d-waifu@main/assets/live2d.js"></script>
<script src="https://cdn.jsdelivr.net/gh/whyyy-404/live2d-waifu@main/assets/live2d-static-api.js"></script>
<script src="https://cdn.jsdelivr.net/gh/whyyy-404/live2d-waifu@main/assets/waifu-tips.js"></script>

<!-- 4. 装静态 API，然后启动 -->
<script>
  fetch('https://cdn.jsdelivr.net/gh/whyyy-404/live2d-models@main/models.json')
    .then(function (r) { return r.json(); })
    .then(function (data) {
      var api = createStaticModelAPI({
        base: 'https://cdn.jsdelivr.net/gh/whyyy-404/live2d-models@main/',
        data: data
      });
      api.install();   // 接管 get / switch / rand / *_textures 五个接口

      live2d_settings['modelId'] = 1;
      live2d_settings['modelTexturesId'] = 0;
      live2d_settings['waifuEdgeSide'] = 'right:0';
      live2d_settings['modelAPI'] = 'https://cdn.jsdelivr.net/gh/whyyy-404/live2d-models@main/api/';

      initModel('https://cdn.jsdelivr.net/gh/whyyy-404/live2d-waifu@main/assets/waifu-tips.json');
    });
</script>
为什么需要 api.install()？ 库本来是对着 fghrsh 的 PHP 后端写的，会请求 get/、switch/ 这些接口。 live2d-static-api.js 把这些请求在浏览器里就地应答掉， 所以不需要任何后端。

常用配置项

全部写在 initModel() 之前。 完整清单见 README。

modelId
默认角色。1 Pio · 2 Tia · 3 22娘 · 4 33娘 · 5 雫 · 6 海王星 · 7 舰娘
modelTexturesId
默认皮肤编号，0 表示原皮
modelStorage
是否记住用户选的角色与皮肤（默认 true）
waifuEdgeSide
停靠位置，'right:0' 或 'left:0'
waifuMinWidth
页面窄于此宽度时隐藏，'disable' 表示永不隐藏
waifuDraggable
拖拽模式，'axis-x'（吸附边缘）或 'disable'
waifuDraggableSnap
吸附动画时长（毫秒），默认 1000
showHitokoto
是否显示一言按钮（默认 true）
hitokotoInterval
空闲时自动换一言的间隔（毫秒），0 表示只手动触发
canCloseLive2d
是否显示「关闭」按钮
canSwitchModel
是否显示「换角色」按钮
canSwitchTextures
是否显示「换皮肤」按钮
canTakeScreenshot
是否显示「拍照」按钮
canHideWaifu
是否显示「悬停隐藏」按钮
waifuToolTop
工具栏距顶部的距离，默认 '30px'
storage
自定义存储实现，用于把记忆换成 GM 存储等

换掉默认存储

默认用 localStorage，按网站分别记忆。 想跨网站同步（比如在用户脚本里），覆盖 storage 即可： 

live2d_settings['storage'] = {
  save: function (key, value) { GM_setValue(key, value); },
  load: function (key) { return GM_getValue(key, null); }
};

自定义台词

台词全部放在一个 JSON 里。想换成自己的风格，把这个文件下载下来改， 或者用自己的地址替换掉 initModel() 的参数。 

// 用你自己的台词文件
initModel('https://your-site.com/my-waifu-tips.json');

文件结构

{
  "waifu": {
    "hour_tips": {
      "t7-11": ["上午好~", "今天也要加油"]
    },
    "model_message": {
      "1": ["来自 Potion Maker 的 Pio 酱"]
    }
  },
  "mouseover": [
    { "selector": ".waifu-tool .el-icon-user", "text": ["要换角色吗？"] }
  ],
  "click": [
    { "selector": ".waifu #live2d", "text": ["别戳我啦"] }
  ],
  "seasons": [
    { "date": "01/01", "text": ["元旦快乐"] }
  ]
}
seasons 的 date 只支持公历，格式 MM/DD 或 MM/DD-MM/DD。 文本里的 {year} 会替换成当前年份。
